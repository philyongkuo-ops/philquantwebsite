# Heidegger Capital website

A responsive, single-page corporate website built with plain HTML, CSS and JavaScript.

## Preview

Open `index.html` in a modern browser. No build step is required. The page uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.

## Files

- `index.html` — page content and semantic structure
- `styles.css` — responsive layout, typography and visual styling
- `script.js` — mobile navigation and current copyright year
